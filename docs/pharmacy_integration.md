# Pharmacy Connect Integration Status

## Overview
AI Health Clinic provides verified external starting points to official Indian pharmacy platforms. The application is honest about its capabilities: it does not fabricate real-time stock, simulate false checkout orders, or collect payment details.

## Supported Official Destinations
1. **Amazon Pharmacy**: `https://www.amazon.in/pharmacy`
2. **Blinkit — Medicines**: `https://blinkit.com/cn/medicines/cid/287/7275`
3. **Swiggy Instamart**: `https://www.swiggy.com/instamart`
4. **Tata 1mg**: `https://www.1mg.com/`
5. **Apollo Pharmacy**: `https://www.apollopharmacy.in/`
6. **PharmEasy**: `https://pharmeasy.in/online-medicine-order`
7. **Netmeds**: `https://www.netmeds.com/c/`

## Integration Status
- External link routing: **Active & Verified**
- Direct in-app dispensing: **Disabled by Design**
- Live inventory API: **Marked Unconfigured** (real-time price and stock checks must be confirmed on the external pharmacy portal).
